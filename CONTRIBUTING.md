# Contributing to Pathway

Thank you for considering contributing to Pathway! This project exists to help young people in India navigate difficult life situations — your contribution, big or small, matters.

---

## 🌱 Before You Start

- Read the [README](README.md) to understand what Pathway is and where it's headed
- Check the open [Issues](../../issues) for tasks that need help
- Look for issues labeled `good first issue` if you are new to the project

---

## 🛠️ How to Contribute

### 1. Fork & Clone

```bash
git clone https://github.com/ShreevathsaMB/Pathway.git
cd Pathway
```

### 2. Create a Branch

```bash
git checkout -b feature/your-feature-name
# or
git checkout -b fix/bug-description
```

### 3. Set Up Locally

Follow the [Getting Started](README.md#-quick-start) steps in the README.

### 4. Make Your Changes

- Keep your changes focused — one feature or fix per pull request
- Test your changes locally before submitting
- Follow the existing code style (TypeScript for frontend, Python/Django for backend)

### 5. Commit Clearly

```bash
git commit -m "feat: add crisis detection to AI chat"
git commit -m "fix: community card duplication on Home"
git commit -m "docs: update CONTRIBUTING with backend tips"
```

### 6. Open a Pull Request

- Describe **what** you changed and **why**
- Link to the issue it resolves if applicable (e.g. `Closes #12`)
- Add screenshots if it's a UI change

## 📋 Areas Where Help is Most Needed

| Area | Details |
|---|---|
| 🎨 Frontend | Rebuild 6-page structure, fix UI bugs, mobile responsiveness |
| 🤖 AI Module | Connect to free LLM (Gemini, Groq, OpenRouter), crisis detection |
| 🔐 Backend | Guest mode, rate limiting, Google sign-in |
| 🌍 Internationalization | Add helplines and legal info for countries outside India |
| ⚖️ Content Review | Legal accuracy (IPC, POCSO, BNS) — lawyers and counselors welcome |
| 🚀 Deployment | Low-cost hosting advice for Django + MongoDB + React |

---

## 🚫 Please Don't

- Submit large, unrelated changes in one PR — keep it focused
- Remove or change safety-related content (helplines, legal info) without discussion
- Expose real user data or API keys in any commit

---
